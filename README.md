# LibertyReserve2_0

Репозиторий с экспортами чата **Liberty Reserve 2.0**, скриптами анализа и сгенерированной Markdown-вики. Проект помогает быстро ориентироваться в многолетней истории чата: участниках, темах, всплесках активности, внутреннем лоре и ссылках на исходные сообщения.

## Что внутри

- `chats_raw/` - годовые Markdown-экспорты исходного чата.
- `Liberty_Reserve_Wiki/` - сгенерированная вики для чтения в Obsidian или любом Markdown-редакторе.
- `build_wiki.py` - основной модуль парсинга, статистики и генерации вики.
- `analyze_chats.py` - точка входа для полной пересборки вики.
- `analyze_evolution.py` - анализ тематической и лексической эволюции выбранных участников.
- `summary.py` - краткий консольный вывод по `user_evolution.json`.
- `*.md` в корне - отдельные аналитические заметки и сводки.
- `user_evolution.json` - результат анализа эволюции участников.

## Возможности

- Подсчет сообщений, текстовых сообщений, вложений и ответов.
- Рейтинг участников по активности.
- Автоматическое определение тематик сообщений по регулярным выражениям.
- Генерация страниц участников, тем, хронологии и внутреннего лора.
- Ссылки из вики на конкретные сообщения в `chats_raw`.
- Отдельный анализ изменения словаря и тем выбранных участников по годам.

## Требования

Нужен Python 3. Скрипты используют только стандартную библиотеку Python, поэтому отдельная установка зависимостей не требуется.

Проверить версию:

```bash
python3 --version
```

## Быстрый старт

Пересобрать вики:

```bash
python3 analyze_chats.py
```

После выполнения скрипт обновит содержимое `Liberty_Reserve_Wiki/` и выведет краткую статистику:

```text
messages=... participants=... days=... topics=...
```

Сгенерировать JSON с эволюцией выбранных участников:

```bash
python3 analyze_evolution.py
```

Посмотреть краткую сводку по этому JSON:

```bash
python3 summary.py
```

## Как читать вики

Главная страница находится в:

```text
Liberty_Reserve_Wiki/index.md
```

Удобнее всего открыть папку `Liberty_Reserve_Wiki/` как Obsidian vault. Внутренние ссылки вида `[[Участники/Топ Участников|Участники и роли]]` рассчитаны на Obsidian-совместимый Markdown.

Ссылки `контекст` ведут обратно к исходным файлам в `chats_raw/`. Если редактор не открывает якорь автоматически, можно открыть нужный файл и найти сообщение поиском по формату:

```text
### [ID_СООБЩЕНИЯ]
```

## Структура данных

Исходные сообщения ожидаются в Markdown-файлах внутри `chats_raw/`. Парсер ищет заголовки сообщений формата:

```text
### [123456] Имя участника · 2024-01-31 12:34:56
```

Текст до следующего такого заголовка считается содержимым сообщения. Блоки вложений, пересылок и служебные строки частично очищаются перед анализом.

## Настройка тем

Темы задаются в `build_wiki.py` в словаре `TOPICS`. Каждая тема содержит набор регулярных выражений. Чтобы добавить или изменить классификацию:

1. Откройте `build_wiki.py`.
2. Измените `TOPICS`.
3. Запустите `python3 analyze_chats.py`.

Стоп-слова для частотного анализа находятся в `STOPWORDS`.

## Приватность

Репозиторий содержит реальные экспортированные сообщения, имена участников, цитаты и автоматически сгенерированные профили. Не публикуйте его целиком без проверки содержимого и согласия людей, которых можно идентифицировать по данным.

## Ограничения

- Тематическая классификация основана на регулярных выражениях и может ошибаться.
- Сводки и профили генерируются статистически, поэтому спорные выводы нужно проверять по исходным сообщениям.
- Скрипты рассчитаны на текущий формат Markdown-экспортов; при изменении формата может потребоваться правка `HEADER_RE` и логики парсинга.
